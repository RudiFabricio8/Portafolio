## Proyectos incluidos

### TutorFinder
Plataforma académica para conectar estudiantes con tutores mediante perfiles, materias, solicitudes, sesiones, reseñas y reportes.

### Reserva El Matilisguate
Sistema CRUD para administrar árboles, cuidadores, visitas, reportes y tratamientos.

### Laboratorio de análisis clínicos
Diseño y revisión de base de datos con énfasis en seguridad, integridad, normalización y reglas de negocio.

### Infraestructura y despliegue
Prácticas con AWS EC2, Ubuntu, Apache y fundamentos de despliegue de servicios.
